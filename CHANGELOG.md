## 0.1.0-demo

Initial demo release of Legalyze.

Included:
- FastAPI backend
- Qt6 desktop client
- login / register
- document upload and parsing
- RAG over user documents
- official law ingestion from `pravo.gov.ru`
- demo request limits
- device-bound demo protection
- landing page and donation link
- Railway deployment files
- GitHub release metadata and funding link
