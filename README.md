# Legalyze (Windows/Linux)

`Legalyze` — это desktop AI-ассистент для анализа юридических документов и информационных консультаций.

Сервис позволяет загружать договоры и другие документы для автоматического анализа с использованием технологий искусственного интеллекта. Пользователь может получать краткие разборы, выявление потенциальных рисков, пояснение отдельных пунктов договора и ответы на вопросы по содержанию документов.

## КАК ЗАПУСКАТЬ?

### Windows
1. Скачайте архив Legalyze-Windows.7z
2. Распакуйте его в удобную папку
3. Запустите файл Legalyze.exe

### Linux
1. Скачайте архив Legalyze-Linux.tar.gz
2. Распакуйте его в удобную папку
3. Откройте терминал в распакованной папке
4. Выполните:
   `chmod +x Legalyze`
   `./Legalyze`
   
## Функционал включает:

- анализ PDF и текстовых документов;
- поиск потенциально рискованных условий;
- краткое объяснение юридических формулировок;
- AI-чат для информационных консультаций;
- структурированные ответы с указанием источников и нормативной информации.

## Что входит в проект

- `backend/` — FastAPI сервер
- `qt_client/` — клиент на Qt/C++

## Важное предупреждение

Legalyze — это информационный AI-ассистент.
Он не заменяет профессиональную юридическую консультацию, адвоката или официальное правовое заключение.
